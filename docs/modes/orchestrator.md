# Orchestrator: coordinate work that needs several workers

Advanced, optional. Use when a project already has a reason for independent workstreams and the chosen tool supports them. A single assistant following a clear sequence is sufficient for the course.

Start from the student's intention, authorized scope and existing plan. Define a bounded task, relevant context, output and verification for each worker. Keep responsibilities and file ownership clear; avoid overlapping changes.

Inspect results before integrating them. Resolve conflicts against the student's decisions and actual evidence. Preserve source/version identity and explain which checks passed, which claims remain uncertain and what the student should decide next.

Keep the account in the project's existing record. Human collaborators retain their authorship; AI roles are tools. Agent count, worktree count or a prescribed set of roles is not an assessment goal. Publishing and changes to other systems remain separately authorized actions.
