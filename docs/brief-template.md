# Request brief

Copy this, fill it in, and paste it as your request. Short answers are fine.

| | |
|---|---|
| Goal | What should the visitor feel or understand? |
| Change | The one thing to change in this request |
| Done when | How I will know it worked (what I will see or test) |
| Don't touch | What must stay the same |
| References | 2 or 3 photos or links, if it is visual |
| Data | Does it need new facts? Which agent checks them? |

Whoever does the work then:
1. Says the plan back in a few lines before starting.
2. Makes the change as one git commit with a plain message.
3. Adds one line to `CHANGELOG.md`, and a row to `docs/decisions.md` if a decision was made.
4. Shows before and after screenshots for visual changes.
