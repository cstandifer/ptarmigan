## What I tested and how

**Reading.** CLAUDE.md, `data/README.md`, `research/sources-log.md`, then every file under `spike-build/data/` and `spike-build/web/` line by line. I compared each value in `data.json` and each factual line in the UI and README against the sources log and the honesty rules. I searched every file for U+2012 to U+2015.

**Running.** Served `spike-build/` with `python3 -m http.server 8765` and opened `http://localhost:8765/web/` in headless Chromium (Playwright, SwiftShader WebGL, 1280 x 800, scale 1). The CDN is blocked here, so I served the `three@0.160.0` package from npm in its place. Steps and results:

| Step | Result |
|---|---|
| Load | Scene, banner, panel and clock appear. Year 1850, four values with PLACEHOLDER tags. |
| Walk (Up, W, Shift+W, A, S) | Bird moves and follows the ground. Height went 2,020 m, 2,079 m, 2,261 m; band line changed from "Below" to "Inside your habitat band". |
| Space | Clock pauses (button shows Play), Space again resumes. |
| Year slider 1950, 2003, 2020 | Panel and ground update (2020 blends to treeline 2,074 m). |
| Run from 2025 | Clock stops at 2026 by itself, dialog asks for a future, note reads "Today. Choose a future to go on." |
| Escape on the dialog | Dialog stays open, as intended. |
| Choose each future, jump to 2050 and 2100 | Values switch per future (usual 2100: treeline 2,400 m; action 2100: 2,200 m). Future and pathway shown next to the year. |
| Drag back to 2000, then to 2070 | Choice clears; the clock holds at 2026 and asks again. |
| Run from 2098 | Reaches 2100, stops, note "End of the timeline." Still 2100 five seconds later and after pressing Space and Play. No loop. |
| Slider focused, arrow keys | Slider and bird both react (item 7). |
| 390 px wide | Panel covers the banner (item 6). |
